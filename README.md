## 사용 방법

1. 원작자의 `FFBE-JP-11.0.0-lapis-26111510.apk` 원본을 준비합니다.
2. 위 패처 APK를 설치하고 실행합니다.
3. 원본 APK 선택 → 한글 패치 시작 → 검증 완료 뒤 완성 APK 설치 순서로 진행합니다.
4. 기존 우리 JP 한글판은 삭제하지 말고 업데이트 설치합니다. 원본 일본 앱과 우리 한글판은 별도 앱이며, 원본 앱 세이브를 자동 이전하지는 않습니다.

## 업데이트

패처를 실행하면 공개된 새 패처 버전을 확인합니다. 수동으로 **업데이트 확인**을 누를 수도 있습니다. 새 버전의 변경 내역을 보고 다운로드를 선택하면 파일 크기·SHA-256·패키지명·APK 서명을 검사한 뒤 Android 설치 확인 화면을 엽니다.

업데이트 대상은 **한글 패처**입니다. 원본 빌드가 바뀌면 안내된 새 원본 APK를 준비해 다시 선택해야 합니다. 게임을 삭제할 필요는 없습니다. 업데이트 확인이 실패하거나 인터넷이 없어도 이미 포함된 패치의 파일 적용은 사용할 수 있습니다.
