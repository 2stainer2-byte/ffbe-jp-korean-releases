## 설치

1. 원본 `FFBE-JP-11.0.0-lapis-26111923.apk`를 준비합니다.
2. 패처 1.7을 설치하거나 기존 패처에서 업데이트합니다.
3. 패처에서 새 원본 APK를 선택하고 한글 패치를 적용합니다.
4. 검증 완료 뒤 만들어진 한글판을 기존 우리 JP 한글판에 업데이트 설치합니다. 기존 앱을 삭제하지 마세요.

원본 일본 앱과 우리 한글판은 별도 앱이며 원본 앱의 세이브를 자동으로 이전하지 않습니다. 원본 빌드가 바뀌었으므로 이전 원본 APK를 다시 선택하면 적용되지 않습니다.

## 이번 변경

원본의 역사 모드 초반 튜토리얼 소환 수정, 글판 유닛 리미트 버스트 레벨 데이터 보정, 보물상자 보상·스위치 수정, 잘못된 효·딘 중복 배너 제거를 보존했습니다.

기존 스토리·전투·스킬·유닛 이름·메뉴 번역과 트마·슈퍼트마 전투 1회 보상 개별 옵션을 이식했습니다. 현재 소환 목록 1,825개 전부의 한글 제목 연결을 확인했습니다. 기존 자막 이미지 316개를 보존하고 효·딘 배너의 그림 준비 상태에 따른 다른 생성 경로에도 원본 그림 아래 자막을 추가했습니다.

새 번역 문장 추가보다는 최신 원본 대응과 번역 연결 보완이 중심입니다. 일부 고유명·그림 문구는 남아 있습니다. 전체 문장 번역 완료를 뜻하지 않습니다.

## 자동 업데이트와 검증

패처 실행 시 새 패처 버전을 확인하며 수동으로 업데이트를 확인할 수도 있습니다. 받은 파일의 크기·SHA-256·패키지명·서명을 검사한 뒤 Android 설치 화면을 엽니다.

실제 원본에서 Android용 Java 패치 엔진을 최대 힙 32MiB로 실행하여 전체 한글판을 복원하고, 최종 APK의 크기·해시와 일치하는지 검사했습니다. 서명·16KiB 정렬·변경 파일 읽기 검증도 수행했습니다. 실제 휴대폰의 모든 화면과 전체 스토리 직접 플레이는 검증하지 않았습니다.

공개 첨부는 **패처 APK와 자동 업데이트용 `release.json` 두 개**입니다. 변경 내역은 릴리스 본문에 적습니다. 소스·추가 검증 자료는 개인 보관하며 원본·완성 게임 APK 전체, 개인 번역 자료 묶음, 서명키·비밀번호·세이브를 공개 첨부로 올리지 않습니다. 패처 APK에는 검증한 변경분이 포함됩니다.
