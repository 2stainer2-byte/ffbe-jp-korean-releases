## 적용 방법

1. 원작자의 `FFBE-JP-11.0.0-lapis-26111914.apk` 원본을 준비합니다.
2. 패처 1.6을 설치하거나 기존 패처를 업데이트합니다.
3. 원본 APK 선택 → 한글 패치 시작 → 검증 완료 뒤 완성 APK 설치 순서로 진행합니다.
4. 기존 우리 JP 한글판은 삭제하지 말고 업데이트 설치하세요. 기존 우리 한글판과 같은 패키지·서명으로 설치합니다.

이번 버전에는 새 **원본 build26111914**가 필요합니다. 패처는 원본의 전체 크기와 SHA-256을 검사합니다. 원본 일본 앱과 우리 한글판은 별도 앱이며, 원본 앱의 세이브를 자동 이전하지 않습니다.

## 한글 0.11 범위

새 원본 build26111914에 기존 스토리·전투·메뉴 번역과 트마·슈퍼트마 개별 옵션을 이식했습니다. 역사 모드·모그리 합성·조각 교환소 검색·소환 확률 안내를 추가 번역하고, 선택 소환에서 빠진 시대·출시일 검사도 보완했습니다.

소환 목록용 이미지 316개에는 원래 그림을 보존한 채 아래에 작은 한글 자막을 붙였습니다. 현재 원본 캐시의 소환 1,826개 전체에서 상세·확률 화면 제목을 한글로 표시합니다. 원본 그림이 암호화된 13개 목록은 기존 그림을 유지합니다. 원본 변경 내용과 자체 수정, 현재 검사와 이전 기록을 계승한 범위는 릴리스 안내에서 구분합니다.

원본 APK와 별도 한글 패처 방식, 기존 GitHub 자동 업데이트 경로는 유지합니다. 일부 고유명·이미지 문구는 남아 있으며, 게임의 모든 문장을 번역 완료했다는 뜻은 아닙니다.

## 자동 업데이트와 검증

패처 실행 시 새 패처 버전을 확인하며, 수동으로 **업데이트 확인**을 누를 수도 있습니다. 다운로드한 파일의 크기·SHA-256·패키지명·서명을 검사한 뒤 Android 설치 화면을 엽니다.

업데이트 대상은 한글 패처입니다. 원본 빌드가 바뀌면 안내된 새 원본을 다시 선택해야 합니다. 인터넷이 없어도 이미 포함된 변경분의 적용은 사용할 수 있습니다.

배포 전에 실제 원본에서 Java 패치 엔진으로 전체 출력 APK를 복원하여 최종 서명 파일과 크기·SHA-256을 대조합니다. 서명·16KiB 정렬과 현재 이식 범위의 검증 기록을 확인합니다. **실제 Android 기기에서의 전체 스토리 완주와 모든 화면 렌더링은 검증하지 않았습니다.** 스토리 검사 수치와 현재·계승된 근거의 범위는 릴리스 안내를 확인하세요.

공개 첨부는 패처 APK와 자동 업데이트용 release.json 두 개입니다. 변경 내역은 릴리스 본문에서 확인할 수 있습니다. 해시 목록·패처 소스 ZIP·별도 안내 파일은 개인 보관합니다. 원본·완성 게임 APK 전체와 개인 전체 번역 자료, 게임 DAT·텍스처, 세이브, 서명키·암호는 별도 공개 파일로 올리지 않습니다. 패처 APK에는 기존 방식대로 검증된 변경분을 포함합니다.
