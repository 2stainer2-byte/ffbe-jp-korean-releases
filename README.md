## 설치

1. `FFBE-JP-11.0.0-lapis-26112115.apk` 원본을 준비합니다.
2. 패처 1.8을 설치하거나 기존 패처에서 업데이트합니다.
3. 패처에서 새 원본을 선택하고 한글 패치를 적용합니다.
4. 검증 완료 뒤 만들어진 한글판을 기존 우리 JP 한글판에 업데이트 설치합니다. 기존 앱을 삭제하지 마세요.

원본 일본 앱과 우리 한글판은 별도 앱이며 원본 앱의 세이브를 자동 이전하지 않습니다. 이번 패처는 이전 원본 26111923에 적용되지 않습니다.

## 이번 변경

원본의 엄선 NV 11연속 소환·월별 제한, 무료 소환 갱신, 시대별 소환 제한, 크로니클 보너스·보스 퀘스트 조건·레이드 보상·보물상자 수정과 새 서버 실행 경로를 유지했습니다.

한국어 스토리 5,743행과 전투 2,064셀을 원본의 새 줄바꿈 정책에 맞춰 재배치하고 본문·제어 태그·ID·행 순서를 보존했습니다. 현재 소환 제목 1,798개 전체를 연결했고, 변경된 배너 87개와 새 원본 그림 38개에 아래 한글 자막을 보완했습니다. 기존 자막 PNG 206개는 픽셀·색·투명도 그대로 압축했습니다.

새 상점의 주간 구매 제한 라벨·도움말, 상품 이름과 크로니클 보너스 표시를 추가 번역했습니다. 기존 스토리·스킬·유닛 이름·메뉴 번역과 트마·슈퍼트마 전투 1회 보상 개별 옵션을 유지했습니다.

원본 문서의 레인&라스웰 포함 설명은 현재 파일의 비소환 플래그와 달라 확인되지 않았습니다. 원본 소환 풀은 임의로 바꾸지 않았습니다. 일부 고유명·그림 문구는 남아 있으며 모든 문장의 번역 완료를 뜻하지 않습니다.

## 자동 업데이트와 검증

패처 실행 시 새 버전을 확인하며 수동 업데이트 확인도 가능합니다. 파일 크기·SHA-256·패키지명·서명을 검사한 뒤 Android 설치 화면을 엽니다. 공개 첨부는 **패처 APK와 자동 업데이트용 `release.json` 두 개**입니다.

실제 새 원본에서 Android용 Java 엔진을 최대 힙 32MiB로 실행해 전체 한글판을 복원하고 최종 APK와 크기·해시를 대조했습니다. 서명·16KiB 정렬·원본 비표시 데이터 보존 및 소환·트마 회귀 검사도 수행했습니다. 실제 휴대폰의 모든 화면과 전체 스토리 직접 플레이는 검증하지 않았습니다. 새 대사 크기 태그의 실제 기기 표시도 검증 범위 밖입니다.

변경 내역은 릴리스 본문에 적습니다. 개인 소스·검증 자료는 별도 보관합니다. 원본·완성 게임 APK 전체, 개인 번역 묶음, 서명키·비밀번호·세이브를 공개 첨부로 올리지 않습니다. 패처 APK에는 검증한 변경분이 포함됩니다.
