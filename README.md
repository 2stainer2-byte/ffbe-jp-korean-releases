1. 원작자의 `FFBE-JP-11.0.0-lapis-26111713.apk` 원본을 준비합니다.

## 업데이트

패처를 실행하면 공개된 새 패처 버전을 확인합니다. 수동으로 **업데이트 확인**을 누를 수도 있습니다. 변경 내역을 보고 다운로드를 선택하면 크기·SHA-256·패키지명·서명을 검사한 뒤 Android 설치 확인 화면을 엽니다.

업데이트 대상은 **한글 패처**입니다. 원본 빌드가 바뀌면 안내된 새 원본 APK를 준비해 다시 선택해야 합니다. 게임을 삭제할 필요는 없습니다. 인터넷이 없어도 이미 포함된 패치의 파일 적용은 사용할 수 있습니다.

## 검증과 자료 범위

실제 원본에서 Java 패치 엔진으로 전체 출력 APK를 복원해 최종 서명 APK의 크기·SHA-256과 대조했습니다. 서명·16KiB 정렬·번역 보존·게임 수치 보존·옵션 독립 동작과 캐시 갱신도 검사했습니다.

스토리 데이터는 시즌 5 마지막 구간까지 있으며, 본편 미션 2,817개·맵 미션 206개의 연결 검사와 분리된 진행 함수 검사가 통과했습니다. **실제 Android 기기에서의 설치·전체 스토리 완주 검증은 하지 않았으며, 전 구간 무오류를 보증하지 않습니다.**

공개 소스 ZIP은 패처·업데이트·배포 도구 범위입니다. 게임 DAT·전체 텍스처·세이브·원본 및 완성 게임 APK·서명키·암호는 공개 소스에 넣지 않습니다.
