## 적용 방법

1. 원작자의 `FFBE-JP-11.0.0-lapis-26111713.apk` 원본을 준비합니다.
2. 패처 1.5를 설치하거나 기존 패처를 업데이트합니다.
3. 원본 APK 선택 → 한글 패치 시작 → 검증 완료 뒤 완성 APK 설치 순서로 진행합니다.
4. 기존 우리 JP 한글판은 삭제하지 말고 업데이트 설치하세요. 원본 일본 앱과 우리 한글판은 별도 앱이며, 원본 앱의 세이브를 자동 이전하지 않습니다.

원본 빌드는 0.09 때와 같습니다. 이미 준비한 정확한 build26111713 원본을 다시 사용할 수 있습니다. 이름만 바꾼 예전 빌드나 이미 한글화한 APK는 입력으로 사용할 수 없습니다.

## 한글 0.10 수정 범위

- 0.09 이식에서 빠졌던 공통 메뉴 한글 표시를 복구하고, 차원의 틈과 유사한 상단 메뉴·탭의 한글화를 보강합니다.
- 다크 비전 44~54회에서 누락된 이름 이미지 11개를 보완하고, 다크 비전·월드 오브 비전 전체 회차의 이름 표시와 로딩 경로를 함께 점검합니다.
- 글자형 배너는 원본의 파란 배경·장식 테두리를 유지하면서 한글 이름을 표시합니다. 정확히 확인된 기존 이미지 캐시도 업데이트합니다.
- 이전 스토리·마스터·전투 번역, 필터와 커스텀 화면 한글화, 전투 1회 클리어 트마·슈퍼트마 개별 스위치는 유지합니다. 미설정 기본값은 모두 꺼짐입니다.

이 버전은 같은 원본 build26111713 위의 자체 표시 수정입니다. 새 원본 업데이트나 스토리 추가로 안내하지 않습니다. 릴리스별 최종 적용 항목과 검증 범위는 변경 내역을 확인하세요. 일부 고유명·이미지 문구는 남아 있으며, 게임의 모든 문장을 번역 완료했다는 뜻은 아닙니다.

## 자동 업데이트와 검증

패처 실행 시 새 패처 버전을 확인하며, 수동으로 **업데이트 확인**을 누를 수도 있습니다. 다운로드한 파일의 크기·SHA-256·패키지명·서명을 검사한 뒤 Android 설치 화면을 엽니다.

업데이트 대상은 한글 패처입니다. 원본 빌드가 바뀌면 안내된 새 원본을 다시 선택해야 합니다. 인터넷이 없어도 이미 포함된 변경분의 적용은 사용할 수 있습니다.

배포 전에 실제 원본에서 Java 패치 엔진으로 전체 출력 APK를 복원하여 최종 서명 파일과 크기·SHA-256을 대조합니다. 서명·16KiB 정렬과 현재 수정 범위의 표시·배경 보존도 검사합니다. 스토리 본편 미션 2,817개·맵 미션 206개의 연결 검사는 앞선 0.09 기록을 계승합니다. **실제 Android 기기에서의 전체 스토리 완주와 모든 화면 렌더링은 검증하지 않았습니다.**

공개 파일은 패처 APK, release.json, SHA256SUMS.txt, 패처 전용 소스 ZIP, release-notes.txt입니다. 원본·완성 게임 APK 전체와 개인 전체 번역 자료, 게임 DAT·텍스처, 세이브, 서명키·암호는 별도 공개 파일로 올리지 않습니다. 패처 APK에는 기존 방식대로 검증된 변경분을 포함합니다.
